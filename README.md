# World Casino

iPhone 14 Pro Max를 우선 기준으로 만든 Expo 기반 모바일 앱입니다. 웹으로도 빌드해 GitHub Pages에 배포합니다.

## 지금 플레이할 수 있는 게임

| 분류 | 게임 |
| --- | --- |
| 카지노 | 블랙잭 · 유럽식 룰렛 · 바카라 · 크랩스 · 식보 · 슬롯 · 파치슬롯 |
| 포커·카드 | 텍사스 홀덤 · 오마하 · 세븐 포커 · 파이브 카드 드로우 · 비디오 포커 · 하이로우 |
| 마작 | 리치 마작 · 중국식 마작 · 홍콩 마작 · 사천 마작 |

한국 전통·레이싱·세계 게임 카테고리는 목록만 있고 아직 준비 중입니다.

## 게임별 구현 범위

**블랙잭** — 히트·스탠드·더블다운·스플릿·보험. 딜러는 17에서 멈춥니다. 스플릿한 손의 21은 블랙잭이 아니라 일반 21로 정산합니다.

**룰렛** — 유럽식 단일 0(37칸). 숫자·색상·홀짝·구간·다스 베팅. 휠이 2단계로 감속하며 마커가 가리키는 숫자를 실시간으로 보여줍니다.

**바카라** — 플레이어·뱅커·타이. 3장째 뽑기 규칙을 표준 표대로 판정하고 뱅커 승리에 5% 커미션을 뗍니다.

**포커류** — 7장 중 최적 5장 탐색, 오마하의 홀 2장 + 커뮤니티 3장 제약, 하이로우의 8-or-better 로우 판정.

## 리치 마작

- 리치 · 더블리치 · 일발 · 멘젠쯔모 · 후리텐(영구·일시)
- 치 · 퐁 · 대명깡 · 암깡 · 가깡 · 창깡 · 영상개화
- 도라 · 뒷도라 · 깡도라 (왕패 14장을 영상패 4장 + 표시패 10장 구조로 관리)
- 자풍패 · 장풍패를 자리와 국에 맞게 판정 (더블 동/남 포함)
- 부 계산: 대기 형태(양면·간짱·변짱·단기·샹퐁), 가치패 머리, 공개/비공개 커쯔·깡, 핑후, 칠대자 25부
- 역만: 국사무쌍 · 대삼원 · 대사희 · 소사희 · 자일색 · 청노두 · 녹일색 · 구련보등 · 사암각 · 사깡쯔 · 천화 · 지화
- 더블 역만: 국사무쌍 13면 · 순정구련보등 · 사암각 단기 · 대사희
- 다중 론: 방총자 기준 우선순위, 두절(head bump) 옵션, 삼가화 유국
- 도중유국: 구종구패 · 사풍연타 · 사가리치 · 사개깡
- 특수 유국: 유국만관
- 반장전 종료: 들통 · 서입 연장 · 아가리야메 · 노텐 벌부
- 컴퓨터 판단: 현물 · 스지 · 벽 · 자패 안전도를 계산한 방어와, 텐파이 여부에 따른 밀기/내리기

남은 것: 일부 마이너 역, 로컬 룰 옵션(적도라 등), 상대 텐파이 추정 정밀화.

## 지갑과 기록

- 코인은 로컬(AsyncStorage)에 저장됩니다. 현금 환전은 없습니다.
- 최근 100판의 기록을 게임·결과·베팅·손익과 함께 저장합니다.
- 난이도(베팅 등급)도 로컬에 저장됩니다.

## 개발

```sh
pnpm install
pnpm start        # Expo 개발 서버 — QR을 Expo Go로 스캔
pnpm typecheck    # TypeScript strict 검사
pnpm test         # 게임 규칙 자동 테스트
```

게임 규칙은 화면과 분리되어 `src/`에 있고, 각 모듈은 난수를 주입받을 수 있어 결정적으로 테스트됩니다. 규칙별 테스트는 `tests/`에 있습니다.

`main`에 푸시하면 GitHub Actions가 `expo export --platform web`으로 빌드해 GitHub Pages에 배포합니다.
