# World Casino

iPhone 14 Pro Max를 우선 기준으로 만든 Expo 기반 모바일 앱 골격입니다.

현재 포함된 기능:

- 카지노 정문 시작 화면
- 홈, 게임, 지갑, 기록, 설정 하단 메뉴
- 6개 게임 카테고리
- 10,000 WC 로컬 저장
- 기본 난이도 로컬 저장
- 지갑 비교 통계와 기록 예시 화면
- 카지노 카테고리 게임 목록
- 블랙잭 난이도별 베팅 선택 화면

현재 블랙잭은 설정 화면까지 연결되어 있으며 실제 게임판은 다음 단계에서 구현합니다.

## 실행

```sh
pnpm start
```

Expo Go에서 표시되는 QR 코드를 스캔하면 실제 iPhone에서 확인할 수 있습니다.
