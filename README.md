# World Casino

iPhone 14 Pro Max를 우선 기준으로 만든 Expo 기반 모바일 앱 골격입니다.

현재 포함된 기능:

- 카지노 정문 시작 화면
- 홈, 게임, 지갑, 기록, 설정 하단 메뉴
- 6개 게임 카테고리와 32개 게임 목록
- 모든 카테고리의 공통 게임 안내 화면
- 10,000 WC 로컬 저장
- 기본 난이도 로컬 저장
- 지갑 비교 통계와 기록 예시 화면
- 한국 전통, 카지노, 포커·카드, 마작, 레이싱, 세계 게임 목록
- 블랙잭 난이도별 베팅 선택 화면
- 실제 블랙잭 카드 배분, 히트, 스탠드, 딜러 자동 진행
- 블랙잭·승리·패배·무승부 코인 정산
- 경기 기록과 지갑 손익 자동 저장
- 블랙잭 규칙 자동 테스트

현재 블랙잭과 유럽식 룰렛을 플레이할 수 있습니다. 블랙잭은 더블다운, 스플릿, 보험을 지원하며 룰렛은 숫자, 색상, 홀짝, 구간 베팅을 지원합니다.

## 실행

```sh
pnpm start
```

Expo Go에서 표시되는 QR 코드를 스캔하면 실제 iPhone에서 확인할 수 있습니다.
